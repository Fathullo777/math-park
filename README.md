# Математический парк развлечений

Интерактивный сайт для учеников 1–4 класса: аттракционы, игры, факты, викторина и диплом.

## Запуск

```bash
npm install
npm start
```

Открой [http://localhost:3000](http://localhost:3000).

## Что внутри

- **Аттракционы** — один вопрос за раз, проверка ответов на сервере
- **Серия 🔥** — очки и серия правильных ответов подряд
- **Викторина** — открывается после всех 5 аттракционов
- **Книга ответов** — раздел «Ответы», код учителя: `1234`
- **Диплом** — после успешной викторины (≥ 60%)

Прогресс хранится в `data/sessions.json`.
